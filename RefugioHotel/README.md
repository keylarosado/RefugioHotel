# Refúgio Hotel — Agenda 13

Aplicativo de demonstração desenvolvido com .NET MAUI, C# e XAML para a atividade Agenda 13 de Programação Mobile I.

## Funcionalidades

- Tela inicial do Refúgio Hotel.
- Formulário de hospedagem com Stepper, Picker e DatePicker.
- Data Binding e BindingContext.
- Tela de resumo da reserva.
- Tela Sobre com identificação da desenvolvedora e ano de desenvolvimento.

## Requisitos e plataforma

Este pacote está configurado para compilação Android com .NET 10 (`net10.0-android`).
